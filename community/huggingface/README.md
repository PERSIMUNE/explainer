# ExplaineR

ExplaineR is an R package for interpreting classification and regression models through Shapley analysis, exploring subgroups, and evaluating model performance, fairness, and decision curves.

- [Get ExplaineR on CRAN ↗](https://cran.r-project.org/package=explainer)
- [Documentation and examples](https://persimune.github.io/explainer/articles/)
- [GitHub](https://github.com/PERSIMUNE/explainer)
- [Methods paper](https://doi.org/10.1093/bioadv/vbae049)

Developed by Ramtin Zargari Marandi, PhD. Full project credits are available in the linked repository and paper.
